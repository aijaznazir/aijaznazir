# Aijaz Nazir — Academic Research Website

A visually impressive, responsive academic homepage for GitHub Pages.

## Quick start

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Optional: upload your CV as `cv.pdf`.
4. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
5. Replace the placeholder GitHub, Google Scholar, LinkedIn, email, and project links in `index.html`.

## Customize

Search `index.html` for:
- `your-email@uh.edu`
- `https://github.com/`
- `Google Scholar`
- `LinkedIn`
- project descriptions

The site intentionally uses plain HTML/CSS/JS, so it works directly with GitHub Pages without a build system.
